## Documentation Conventions

To ensure the README table of contents works correctly on GitHub, we follow
GitHub’s automatic heading anchor rules.

- Heading anchors are automatically generated from section titles.
- All letters are converted to lowercase.
- Spaces are replaced with `-`.
- Punctuation is removed.

Example:

## Our Group
→ anchor: `#our-group`

## Sustainability, Accessibility, and Ethics
→ anchor: `#sustainability-accessibility-and-ethics`

The table of contents in `README.md` must reference these anchors.
