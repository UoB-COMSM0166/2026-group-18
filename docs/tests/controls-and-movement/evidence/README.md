# Controls and Movement Test Evidence

This folder stores supporting evidence for Functional Unit 1: Controls and Movement.

Recommended contents:
- screenshots or short recordings for test cases `CM1` to `CM5`
- notes used to complete the `Observed outputs` column
- optional raw measurement files if movement values are recorded

Suggested structure:
- `evidence/CM1_no_input.png`
- `evidence/CM2_thrust_from_stationary.mov`
- `evidence/CM3_left_rotation.mov`
- `evidence/CM4_sustained_thrust.mov`
- `evidence/CM5_screen_wrap.mov`

Use this folder together with the movement test table in `docs/tests/testing.md`.
