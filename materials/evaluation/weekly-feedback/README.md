# Weekly Feedback Archive

Use this folder for all weekly playtest feedback and iteration goals.

## File naming

- Weekly report: `YYYY-MM-DD-weekly-feedback-and-goals.md`
- Optional raw notes: `YYYY-MM-DD-raw-notes.md`

## Recommended workflow

1. Copy `WEEK_TEMPLATE.md`.
2. Fill in feedback summary, priorities, action items, and validation plan.
3. Link items to issue/PR/commit after implementation.
